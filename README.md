# 🎲 台灣官員財產申報資料大富翁 (Taiwan Officials Property Declaration Monopoly)

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)
[![GitHub Pages](https://img.shields.io/badge/Deployment-GitHub%20Pages-blue.svg)](https://pages.github.com/)
[![Data Verification](https://img.shields.io/badge/Data%20Verification-100%25%20Control%20Yuan%20Audited-success.svg)](#資料來源說明與引用出處)

本專案為一套專門整理、分析與比較台灣政府公職人員（包含全台 **22 縣市長**、**第 11 屆 113 位立法委員全員**、以及 **全台 22 縣市議會代表性議員與議長**）依法向監察院及相關機關申報之財產資料的開源網頁應用程式。

已針對 **全台 22 縣市長（含前台北市長柯文哲）**、**全體 113 位第 11 屆立法委員** 與 **全台 22 縣市議會代表性議員/議長** 之財產申報紀錄進行全面查核與數據補齊（總計 202 位官員），確保所有官員均具備完整結構化欄位（包含存款總額、不動產筆數與明細、股票/有價證券金額、債務總額、事業投資及監察院廉政專刊資料來源）。

---

## 🌟 主要功能 (Core Features)

### 1. 🗂️ 全台官員資料庫與 22 縣市分類總覽 (Official Archive & 22 Counties Classification)
* **涵蓋全台中央與地方民代首長**：收錄 23 位縣市首長（含前台北市長柯文哲）、113 位第 11 屆立法委員全員、以及全台 22 縣市議會代表性議員與議長（共 65+ 位縣市議員）。
* **以縣市為分類與多維度關鍵字搜尋**：新增 **22 縣市獨立下拉分類選單**（臺北市、新北市、桃園市、臺中市、臺南市、高雄市、基隆市、新竹市、新竹縣、苗栗縣、彰化縣、南投縣、雲林縣、嘉義市、嘉義縣、屏東縣、宜蘭縣、花蓮縣、臺東縣、澎湖縣、金門縣、連江縣），支援按分類（縣市長、立法委員、縣市議員、22縣市）以及姓名、黨籍、縣市選區即時動態搜尋與數值統計。

### 2. 📜 歷年申報資料查閱 (Filing History & Details)
* **完整欄位結構化呈現**：清楚條列土地、建物（含坐落、面積、持分、取得時間與原因）、車輛、存款總額與帳戶數、有價證券（股票、債券、基金）、保單件數、應收債權、債務細項（房貸、週轉金）及事業投資。
* **資料來源標籤**：明確標註各筆申報資料係來自「監察院原始 PDF 核對」或「權威新聞媒體轉述公報」。

### 3. ⚖️ 官員財產雙人動態側對側比較 (Side-by-Side Comparison)
* **自由選取任意雙官員對照**：提供雙下拉選單介面，並按「🏛️ 縣市長」、「📜 立法委員」及「🪑 22 縣市議會議員」進行分組選單。使用者可在全站 202 位官員中自由選擇任意兩位官員（如蔣萬安 vs 戴錫欽、韓國瑜 vs 黃國昌、傅崐萁 vs 張峻、邱奕勝 vs 謝典林、苗博雅 vs 羅智強）進行即時對比。
* **全方位數據矩陣**：比較最新申報日期、存款、股票/有價證券金額、不動產筆數、債務總額、事業投資及重點觀察疑點。

### 4. 📊 全自動財富與不動產排行榜更新 (Dynamic Wealth & Property Rankings)
* **財富排行榜 (Wealth Rank)**：依「申報總資產（存款＋股票＋事業投資）」與「預估淨財產（總資產減債務）」進行全站官員即時動態排序，並支援按 22 縣市獨立篩選排行榜。
* **不動產排行榜 (Property Rank)**：依申報書列出之土地與建物總筆數進行動態排序，同樣支援按 22 縣市篩選。
* **資料層級與註記說明**：清楚標明各官員之資料取得層級與特殊備註（如未達申報標準或美債/黃金資產未計入之項目）。

### 5. 📈 熱門持股與台積電專題分析 (Top Stocks & TSMC Holders)
* **前 20 大單筆持股排行榜**：全站 202 位官員跨界統計個股或基金申報金額前 20 大明細。
* **誰持有台積電？**：跨官員統計護國神山「台積電 (2330)」持股人數、所有人、股數及申報金額（全面納入 22 縣市議員與議長）。

### 6. 🔍 爭議時間軸與異常觀察 (Timeline & Anomaly Watch Points)
* **爭議時間軸**：整理官員從政履歷、重大家族事件、司法訴訟、罷免案件及財產變動節點。
* **異常觀察卡片**：比對申報表後客觀記錄「值得追查的疑點」（如密集繼承、借款用途未交代、申報後短期申請更正、司法判決與行政裁罰等），並標註關注等級（高/中/低）。

## 🔗 資料來源說明與引用出處 (Data Sources & Citation)

本網站整理之資料均來自公開之政府資訊與權威媒體報導，具體資料來源包括：

1. **監察院公職人員財產申報公報（廉政專刊）**：監察院依公職人員財產申報法定期出版之公報 PDF。
2. **監察院財產申報資料查詢系統** ([priq-out.cy.gov.tw](https://priq-out.cy.gov.tw/GipExtendWeb/wSite/SpecialPublication/baseQuery.jsp))：依法提供民眾查詢之官方資料庫。
3. **民間「立委持股公開平台」** ([legislator-wealth.tw](https://legislator-wealth.tw/))：自動解析監察院公報 PDF 之結構化資料。
4. **中央選舉委員會** ([cef.gov.tw](https://www.cec.gov.tw/))：公職人員候選人登記時依法申報並公開之財產資料。
5. **各縣市議會財產申報現場查閱專區**：依《公職人員財產申報法》第六條規定提供民眾現場查閱。
6. **國內權威新聞媒體報導**：中央通訊社 (CNA)、自由時報、聯合報、中國時報、TVBS、ETtoday、NOWnews、鏡週刊、Newtalk、風傳媒等報導。

## 🚀 GitHub Pages 部署指南 (Deployment Guide)

本專案採用純原生前端技術（HTML5 + CSS3 + Vanilla JavaScript ES6）建置，適合直接託管於 GitHub Pages。

### 部署步驟：
1. 將本專案 Fork 或 Clone 至您的 GitHub 帳號。
2. 進入 Repository 頁面，點選 **Settings** -> **Pages**。
3. 在 **Source** 選項中選擇 `main` (或 `master`) 分支，目錄選擇 `/ (root)`。
4. 點選 **Save**，等待 1-2 分鐘即可完成部署並取得公開存取網址。
